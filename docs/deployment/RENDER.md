# Render configuration

The root `render.yaml` defines the Django service.

- Runtime: Python 3.13.11 (`backend/.python-version`)
- Root directory: `backend`
- Build: install dependencies, run Django checks and collect static files
- Start: apply migrations and start Gunicorn
- Health check: `/api/health/`
- Deployment trigger: after linked GitHub checks pass

Required environment values:

| Variable | Source |
|---|---|
| `DJANGO_SECRET_KEY` | Generated by Render |
| `DJANGO_DEBUG` | `false` |
| `DJANGO_SECURE_SSL_REDIRECT` | `true` |
| `DJANGO_ALLOWED_HOSTS` | `.onrender.com,localhost,127.0.0.1` |
| `DATABASE_URL` | Supabase Session pooler URI |
| `CORS_ALLOWED_ORIGINS` | Exact Cloudflare Pages origin |
| `CSRF_TRUSTED_ORIGINS` | Exact Cloudflare Pages origin |

The included Render start command applies migrations before starting Gunicorn because Render pre-deploy commands are available only on paid web services, private services and background workers. Repeated application of committed Django migrations is safe.
