# ProjFlow 0.1.0 release scope

## Included
- Branded React/Vite application.
- React Router pages: overview, platform overview and system status.
- Django REST Framework API.
- Public liveness and database readiness endpoints.
- UUID-based custom Django user model.
- Email login identifier with case-normalised storage and case-insensitive uniqueness.
- Four seeded global roles.
- Multiple role assignments per user.
- Django administration registration.
- Initial migrations.
- Backend unit/API tests.
- GitHub Actions backend test and frontend build workflow.
- Render Blueprint.
- Cloudflare Pages SPA configuration.

## Not included yet
- Student or lecturer onboarding.
- Student register imports.
- Supervisor allocation.
- Topic proposals and approvals.
- Chapter submissions and review.
- Final submission deadline and reopening.
- Examination groups and panels.
- Individual and collective assessments.
- Grading and result publication.
- Email notifications.
- Private document uploads.
- Production backup automation.

The interface labels future modules as in development. This release is a deployment foundation, not a completed academic management system.
