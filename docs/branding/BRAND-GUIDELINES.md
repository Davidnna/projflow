# ProjFlow Brand Guidelines

**Version:** 1.0  
**Status:** Initial production asset specification  
**Product category:** Final-Year Project Management Platform  
**Tagline:** From Proposal to Final Defence.

## Brand positioning
ProjFlow is a centralised platform for managing, supervising and evaluating final-year academic projects. The identity should communicate professionalism, clarity, accountability, progress and reliability.

## Logo system
- `svg/projflow-logo-primary.svg`: default use on light backgrounds.
- `svg/projflow-logo-reversed.svg`: use on dark backgrounds.
- `svg/projflow-logo-monochrome.svg`: single-colour print or constrained reproduction.
- `svg/projflow-symbol.svg`: standalone brand symbol.
- `svg/projflow-app-icon.svg`: application icon.
- `svg/projflow-favicon.svg`: simplified browser icon.

Use the SVG files where possible. Do not stretch, skew, recolour, rotate, rearrange or add effects to the logo. Preserve its aspect ratio and clear space.

## Colour palette

| Name | Hex | Primary use |
|---|---|---|
| Midnight Navy | `#101C36` | Navigation, headings, dark surfaces |
| Royal Blue | `#2563EB` | Primary actions, links, highlights |
| Teal | `#14B8A6` | Progress, success and positive states |
| Light Grey | `#F1F5F9` | Backgrounds and neutral surfaces |
| White | `#FFFFFF` | Content surfaces and reversed logo elements |

## Typography
- **Montserrat:** brand wordmark and major brand headings.
- **Inter:** application interface, body text, labels, tables and data.

Recommended weights: 700 for brand headings, 600 for section headings, 400–500 for body and interface text.

## Product voice
Use concise, clear, academically appropriate language. Prefer functional labels such as “Submit Project Topic”, “Supervisor Review Required”, “Submission Approved” and “Final Submission Deadline”.

## Interface colour use
- Midnight Navy: primary navigation and major headings.
- Royal Blue: primary actions, links and selected navigation.
- Teal: progress and positive status indicators.
- Light Grey: page backgrounds and neutral sections.

Do not rely on colour alone to communicate status. Pair colour with text or an icon.

## Technical assets
CSS tokens are provided in `projflow-design-tokens.css`. PNG exports and favicon sizes are in the `png/` directory. SVGs are the preferred scalable source assets.

## Brand clearance
This is a working product identity. Trademark, business-name and domain clearance should be completed before public commercial launch.
